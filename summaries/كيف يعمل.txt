# 📘 دليل الاستخدام الشامل: مُنتج ملخصات الماراثون التفاعلية

## 🎯 ما هي هذه الأداة ولماذا نحتاجها؟

**مُنتج ملخصات الماراثون** هي أداة مستقلة (ملف HTML واحد) تعمل على جهازك بدون إنترنت، وتساعدك على:

1. **إنشاء ملخصات قواعد تفاعلية** للطلاب (بدون كتابة كود HTML يدوياً)
2. **دمج الملخصات الجديدة** مع القديمة دون فقدان البيانات
3. **تصدير ملف JSON جاهز** لرفعه على GitHub ليستخدمه الطلاب في منصتهم

### 🔄 كيف تعمل الأداة في السياق العام؟

```
أنت (المدرس) 
    ↓ تُنتج ملخصات باستخدام هذه الأداة
ملف summariesDB.json 
    ↓ ترفعه على GitHub
منصة الطلاب (summaries/index.html)
    ↓ يقرأ الملف ويعرضه
الطالب يرى شرحاً تفاعلياً جميلاً
```

## ️ نظرة عامة على الواجهة

عند فتح الأداة، سترى **3 خطوات رئيسية** في الأعلى:

```
┌─────────────────────────────────────────────────────┐
│  [1] استيراد القديم  [2] إضافة الجديد  [3] التصدير  │
└─────────────────────────────────────────────────────┘
```

كل خطوة لها لون:
- **⚪ رمادي بخط متقطع**: لم تبدأ بعد
- **🟢 أخضر**: قيد العمل
- ** ذهبي**: مكتملة

## 📥 الخطوة 1: استيراد الملف القديم

### متى تستخدم هذه الخطوة؟

| الحالة | الإجراء |
|--------|---------|
| **أول مرة تستخدم الأداة** | اضغط "🆕 ابدأ من الصفر" |
| **عندك ملف summariesDB.json سابق** وتريد إضافة وحدات جديدة | اضغط "📂 اختر ملف" واستورده |

### كيف تستورد الملف القديم؟

1. اضغط زر **"📂 اختر ملف summariesDB.json القديم"**
2. اختر الملف من جهازك
3. ستظهر رسالة خضراء تقول:
   > ✅ تم استيراد **X** ملخص قديم. IDs الجديدة ستبدأ من: **sum_Y**

### ️ لماذا هذا مهم جداً؟

- **يحمي الـ IDs القديمة**: إذا كان عندك ملخصات بـ `sum_1`, `sum_2`, `sum_3`، الأداة ستبدأ الجديدة من `sum_4` تلقائياً
- **يمنع التكرار**: لن تضيف نفس الوحدة مرتين بالخطأ
- **يحافظ على عمل المنصة**: الطلاب الذين وصلوا لـ Unit 2 لن ينكسر رابطهم

## ✏️ الخطوة 2: إضافة ملخص جديد

هذه هي **القلب النابض** للأداة. تنقسم لـ 3 أجزاء:

### 🅰️ الجزء الأول: بيانات المسار والوحدة

```
┌──────────────────────────────────────────────┐
│ المرحلة: [الابتدائية ▼]                      │
│ الصف:    [2 ▼]                               │
│ المنهج:  [OL ▼]                              │
│ الوحدة:  [3 ]                                │
│ العنوان: [المضارع البسيط vs المستمر       ]  │
└──────────────────────────────────────────────
```

**شرح كل حقل:**

| الحقل | ما يجب إدخاله | أمثلة |
|-------|---------------|-------|
| **المرحلة** | المرحلة الدراسية | الابتدائية / الإعدادية / الثانوية |
| **الصف** | رقم الصف | 1, 2, 3, 4, 5, 6 |
| **المنهج** | نوع المنهج | OL / AL / كامبريدج |
| **الوحدة** | رقم الوحدة | 1 إلى 12 |
| **العنوان** | اسم الدرس | "أدوات الاستفهام" / "المضارع المستمر" |

---

### 🅱️ الجزء الثاني: القواعد (Rules) - مع المحرر الغني

هذا هو **الجزء الأهم** والأكثر تميزاً في الأداة.

#### 🔧 المحرر الغني (Rich Text Editor)

بدلاً من كتابة أكواد HTML معقدة مثل `<strong>عادات</strong>`، الأداة تعطيك **أزرار تنسيق** مثل Word:

```
┌──────────────────────────────────────────────┐
│ [B] [I] [Code]                               │ ← أزرار التنسيق
│                                              │
│ نستخدمه للـ عادات وروتين يومي                │ ← اكتب هنا مباشرة
└──────────────────────────────────────────────┘
```

**شرح الأزرار:**

| الزر | الاسم | ماذا يفعل | مثال |
|------|-------|-----------|------|
| **B** | Bold (عريض) | يجعل النص **عريضاً** ومميزاً | "عادات" تصبح **عادات** |
| *I* | Italic (مائل) | يجعل النص *مائلاً* | "روتين" تصبح *روتين* |
| `Code` | Code (كود) | يجعل النص بلون أحمر وخلفية مميزة | "always" تصبح `always` |

####  كيف تكتب قاعدة بشكل صحيح؟

**مثال عملي - قاعدة "المضارع البسيط":**

1. **عنوان القاعدة**: اكتب `1. المضارع البسيط (Present Simple)`

2. **متى نستخدم؟**: 
   - اكتب: `نستخدمه للـ `
   - اضغط زر **B**
   - اكتب: `عادات وروتين يومي`
   - النتيجة: "نستخدمه للـ **عادات وروتين يومي**"

3. **الكلمات المفتاحية**:
   - اكتب: `always` واضغط **Enter**
   - اكتب: `every day` واضغط **Enter**
   - ستظهر كـ "بطاقات" ملونة: `always` × | `every day` ×
   - لحذف كلمة: اضغط × بجانبها

4. **مثال**:
   - اكتب: `I `
   - اضغط **B**
   - اكتب: `play`
   - اضغط **B** مرة أخرى (لإيقاف العريض)
   - اكتب: ` football every Friday.`
   - النتيجة: "I **play** football every Friday."

#### 👀 المعاينة المباشرة (Live Preview)

أسفل كل قاعدة، سترى صندوق أخضر بعنوان **"👀 معاينة مباشرة"**. هذا الصندوق يعرض لك **بالضبط** كيف ستظهر القاعدة للطالب في المنصة.

**لماذا هذا مهم؟**
- ترى الأخطاء فوراً قبل الحفظ
- تتأكد أن التنسيق صحيح
- لا تحتاج لتجربة على المنصة الحقيقية

---

### 🅲️ الجزء الثالث: التحدي السريع (Mini Quiz) - اختياري

هذا جزء **تفاعلي** يظهر في نهاية الملخص لاختبار فهم الطالب.

```
┌──────────────────────────────────────────────┐
│ سؤال التحدي: "Listen! The baby ....... "     │
│                                              │
│ الخيار 1: [cries       ]                     │
│ الخيار 2 ✅: [is crying  ]  ← هذا هو الصحيح  │
│ الخيار 3: [cry         ]                     │
│ الخيار 4: [            ]  ← اتركه فارغاً     │
│                                              │
│ رسالة التغذية: كلمة 'Listen!' تعني أنه يحدث  │
│               الآن.                          │
└──────────────────────────────────────────────┘
```

**قواعد مهمة:**
- **الخيار 2 دائماً هو الصحيح** (الأداة مصممة هكذا)
- إذا لم ترد تحدي، اترك كل الحقول فارغة
- رسالة التغذية تظهر للطالب بعد الإجابة

## 🤖 استيراد كود JSON من الذكاء الاصطناعي

في أعلى الخطوة 2، ستجد صندوقاً أزرق بعنوان **"🤖 استيراد كود JSON من الذكاء الاصطناعي"**.

### متى تستخدم هذا؟

عندما تطلب من الذكاء الاصطناعي (مثل ChatGPT أو Qwen) إنتاج ملخص جاهز، وتعطيك كود JSON.

### طريقتان للاستيراد:

#### الطريقة 1: استيراد ملف JSON
1. احفظ كود JSON الذي أعطاك إياه الذكاء الاصطناعي في ملف (مثل `unit3.json`)
2. اضغط **"📥 استيراد ملف JSON جديد"**
3. اختر الملف

#### الطريقة 2: لصق الكود مباشرة (الأسرع!)
1. اضغط **"📋 لصق كود JSON مباشرة"**
2. ستظهر نافذة منبثقة
3. الصق الكود في المربع الكبير
4. اضغط **"✅ استيراد الكود"**

### ✅ ماذا يحدث بعد الاستيراد؟

- الأداة تتحقق تلقائياً من صحة الكود
- تدمج الملخصات الجديدة مع القديمة
- تحمي الـ IDs من التكرار
- تظهر الملخصات الجديدة بعلامة **"جديد ✨"** خضراء

## 💾 حفظ الملخص في القائمة

بعد ملء البيانات (سواء يدوياً أو بالاستيراد)، اضغط:

**" حفظ الملخص في القائمة"**

**ماذا يحدث؟**
- يُضاف الملخص للقائمة المؤقتة
- يظهر في "معاينة الخطوة 3"
- يمكنك حذفه إذا أردت (زر 🗑️)
- **لم يُصدَّر بعد** (لا يزال في الذاكرة فقط)

---

## 📋 الخطوة 3: معاينة وتصدير الملف المدمج

### 📊 شريط الإحصائيات

في أعلى الخطوة 3، سترى 3 أرقام:

```
[0 ملخص قديم]  [2 ملخص جديد]  [2 الإجمالي]
```

هذا يخبرك:
- كم ملخصاً استوردته من الملف القديم
- كم ملخصاً أضفته الآن
- الإجمالي الذي سيُصدَّر

### 🎴 معاينة البطاقات

كل ملخص يظهر كـ "بطاقة" تحتوي:
- **العنوان** (بالذهبي)
- **الـ ID** (مثل sum_1)
- **المسار** (مثل: ابتدائية - Grade 2 - OL)
- **الوحدة وعدد القواعد**
- **علامة "جديد ✨"** للملخصات المضافة حديثاً

### ️ حذف ملخص جديد

إذا أضفت ملخصاً بالخطأ:
- اضغط زر **"🗑️ حذف"** في بطاقته
- سيُحذف من القائمة المؤقتة
- **الملخصات القديمة لا يمكن حذفها** (لحمايتها)

## 📤 التصدير النهائي

عندما تنتهي من إضافة كل الملخصات المطلوبة، اضغط:

**"📤 تصدير الملف المدمج (summariesDB.json)"**

### ماذا يحدث؟

1. الأداة تجمع كل الملخصات (القديمة + الجديدة)
2. تُنشئ ملف JSON واحد
3. تُنزّله على جهازك باسم `summariesDB.json`
4. تظهر رسالة:
   > ✅ تم تنزيل الملف بنجاح!
   > 📊 يحتوي على X ملخص.
   > 🚀 الخطوة التالية: ارفع الملف إلى مجلد /summaries/ في مستودع GitHub.

### 👁️ معاينة JSON

إذا أردت رؤية الكود قبل التصدير:
- اضغط **"👁️ معاينة JSON"**
- سيظهر مربع نصي يحتوي الكود الكامل
- يمكنك نسخه أو مراجعته

### 👀 معاينة كاملة للطالب

لترى كيف سيظهر الملخص للطالب في المنصة:
- اضغط **"👀 معاينة كاملة للطالب"**
- ستظهر نسخة طبق الأصل من صفحة الطالب
- تشمل: العنوان، القواعد، الكلمات المفتاحية، الأمثلة، والتحدي السريع

## ️ أسئلة شائعة وحلول المشاكل

### ❓ ماذا لو أخطأت في كتابة قاعدة؟

**الحل**: لا تحذف القاعدة كاملة! فقط:
- عدّل النص في المحرر الغني
- المعاينة المباشرة ستحدث فوراً
- اضغط "💾 حفظ" مرة أخرى (سيُحدّث الملخص)

### ❓ ماذا لو أضفت نفس الوحدة مرتين؟

**الحل**: الأداة ذكية! ستتحقق من:
- نفس المرحلة + الصف + المنهج + الوحدة
- إذا وجدت تكراراً، ستنبهك
- يمكنك حذف النسخة المكررة من الخطوة 3

### ❓ ماذا لو أغلقت المتصفح بالخطأ؟

**الحل**: ⚠️ **احذر!** الأداة لا تحفظ تلقائياً في localStorage.
- إذا لم تضغط " حفظ" بعد، ستفقد البيانات
- **نصيحة**: احفظ بشكل متكرر أثناء العمل

### ❓ كيف أعرف أن الملف صالح لـ GitHub؟

**الحل**: قبل الرفع، تأكد من:
1. اسم الملف: `summariesDB.json` (بالضبط)
2. هيكل الملف: يبدأ بـ `{ "summaries": [...] }`
3. لا توجد أخطاء في JSON (الأداة تتحقق تلقائياً)

### ❓ الطالب يرى "الملخص قيد الإعداد" رغم أنني رفعته!

**الأسباب المحتملة**:
1. **Cache المتصفح**: اضغط `Ctrl + F5` لتحديث الصفحة
2. **المسار خاطئ**: تأكد أن الملف في مجلد `/summaries/` وليس في الجذر
3. **البيانات غير متطابقة**: تأكد أن المرحلة/الصف/المنهج/الوحدة في JSON تطابق بيانات الطالب بالضبط

### ❓ كيف أعدل ملخصاً قديماً؟

**الحل**: الأداة الحالية لا تدعم التعديل المباشر للملخصات القديمة. لكن يمكنك:
1. تصدير الملف الحالي
2. فتحه في محرر نصوص (مثل VS Code)
3. تعديل الـ JSON يدوياً
4. إعادة استيراده في الأداة

## 💡 نصائح احترافية

### 1️⃣ نظّم عملك

```
📁 MarathonTools/
── summaries-manager.html    ← الأداة
├── summariesDB.json          ← الملف الحالي (من GitHub)
├── backups/                  ← نسخ احتياطية
│   ├── summariesDB_backup_2024_01.json
│   └── summariesDB_backup_2024_02.json
└── drafts/                   ← مسودات من AI
    ├── unit3_draft.json
    └── unit4_draft.json
```

### 2️⃣ اعمل نسخاً احتياطية

قبل كل عملية دمج كبيرة:
1. انسخ `summariesDB.json` الحالي
2. الصقه في مجلد `backups/`
3. سمّه بتاريخ اليوم
4. ثم اعمل الدمج

### 3️⃣ اختبر قبل الرفع

بعد التصدير:
1. افتح الملف في المتصفح (اسحبه وأفلته)
2. تأكد أنه يعرض JSON بشكل صحيح
3. راجع عدداً عشوائياً من الملخصات
4. ثم ارفعه على GitHub

### 4️⃣ استخدم المعاينة الكاملة

قبل التصدير النهائي:
- اضغط **"👀 معاينة كاملة للطالب"**
- راجع كل قاعدة
- تأكد أن الأمثلة واضحة
- تحقق من التحدي السريع

### 5️⃣ اكتب أمثلة من بيئة الطالب

بدلاً من:
> ❌ "John goes to school in London"

اكتب:
> ✅ "محمد يذهب إلى المدرسة في القاهرة"

هذا يجعل الملخص **أقرب لواقع الطالب** ويزيد تفاعله.
